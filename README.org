#+title: emacs-rpc-bridge

A C++20 Emacs native module implementing a local gRPC bridge into Emacs,
with an Elisp adapter that owns the runtime.  Authoritative plan and
milestone log: =runbook/emacs-rpc-bridge/design-001.org= in the parent
spacemacs repo.  Wire contract: =proto/emacs_rpc.proto= (single schema;
nothing generated is checked in).

Clients talk to Emacs over one Unix-domain socket in a private, owner-only
per-user runtime directory.  No network exposure, no automatic startup at
module load, no retries of side-effecting calls.

* Layout

- =proto/= — the shared wire schema (=emacs_rpc.proto=, package =emacs.rpc.v1=)
- =src/= — module entry (=module.cpp=), gRPC service + queue (=server.cpp=),
  the only env-touching dispatch (=dispatch.cpp=), session handle registry
  (=handles.cpp=), env-free shared types (=bridge.h=, =bridge_internal.h=)
- =lisp/emacs-rpc-bridge.el= — adapter: defcustoms, start/stop owning the
  drain timer, the Lisp helpers the native dispatch funcalls
- =tests/= — =codegen_smoke=, the C++ integration harness
  (=integration_test.cpp= + =emacs_bridge_server.el=), both run by =ctest=
- Nothing language-specific is checked in here; the "Python client"
  section below builds a small consumer from the schema alone, with =uv=,
  and it doubles as the design-TODO-5 runtime acceptance example.

* Requirements

- Emacs 31.1 with native module support and the matching =emacs-module.h=
- CMake 3.21+ (presets), C++20 compiler
- gRPC + protobuf installed explicitly (no silent downloads) in
  =$HOME/local=, supplied through =CMAKE_PREFIX_PATH= in
  =CMakePresets.json=

* Build and check

#+begin_src shell
cmake --preset default            # configure into build/
cmake --build build               # module -> build/libemacs-rpc-bridge.so
ctest --test-dir build            # codegen_smoke + integration_test
#+end_src

The integration harness spawns its own =emacs -Q --batch= running
=tests/emacs_bridge_server.el= (which pumps events so the drain timer
runs), then drives every scenario over the real socket.

* Load into Emacs (the adapter)

** As an installed package (Spacemacs additional packages)

This repository installs as the package =grpc-bridge= (main file
=grpc-bridge.el= at the repository root, mirroring how emacs-jupyter-eval
packages =jupyter-eval=):

#+begin_src elisp
;; .spacemacs.d/emacs-config/layers.el, dotspacemacs-additional-packages:
(grpc-bridge :location (recipe :fetcher github-ssh
               :repo "lesliebinbin/emacs-grpc-ext" :files ("*")))
#+end_src

A package install delivers the elisp only -- the native module (C++/gRPC)
is not shipped as elisp.  On first =require=, =grpc-bridge.el= checks for
=build/libemacs-rpc-bridge.so= next to it and offers to build it in place
with =mise build= (in noninteractive runs it prints the command instead).
The build needs the gRPC toolchain of the Requirements section.

#+begin_src elisp
(require 'grpc-bridge)      ; first require offers `mise build' if needed
(emacs-rpc-bridge-start)    ; explicit start; loading never starts it
#+end_src

** From a source checkout

#+begin_src elisp
(require 'emacs-rpc-bridge)   ; from lisp/emacs-rpc-bridge.el
(emacs-rpc-bridge-start)      ; explicit start; loading never starts it
#+end_src

=emacs-rpc-bridge-start= picks the per-user socket path itself and starts
the drain timer.  Runtime knobs (all fixed at start; nil means the
defcustom):

- =emacs-rpc-bridge-queue-depth= 100 — queue capacity; full queue exerts
  wait-backpressure on clients
- =emacs-rpc-bridge-timer-period= 0.1 s — drain tick (live: :set restarts)
- =emacs-rpc-bridge-max-drain-per-tick= 20 — requests per tick
- =emacs-rpc-bridge-lease-seconds= 300 — inactivity lease; idle sessions
  are closed and their handles freed (0 disables)
- =emacs-rpc-bridge-max-sessions= 32 — concurrent-session quota;
  =OpenSession= fails with RESOURCE_EXHAUSTED when full (0 = unlimited)
- =emacs-rpc-bridge-max-message-bytes= 0 — inbound message cap in bytes
  (0 = the gRPC default of 4 MiB)

The registered native functions are =emacs-rpc-bridge-native-start/drain/
stop/running-p/last-error=; use the adapter, not the natives, in an
interactive Emacs.  =emacs-rpc-bridge-stop= is on =kill-emacs-hook=.

* Python client (a minimal consumer)

The bridge is language-neutral: any gRPC client works.  This section
builds a small Python consumer from scratch with =uv= -- no repository
paths, nothing but the shared schema.  It assumes an Emacs already
running the bridge (Load into Emacs above).

** 1. Dependencies

#+begin_src shell
uv add grpcio grpcio-tools     # inside your uv project
#+end_src

** 2. Copy the wire schema

=proto/emacs_rpc.proto= is the single source of truth -- the client
compiles the very file the server speaks, so the two can never drift.
Copy it into your project (and re-copy when this repository updates it):

#+begin_src shell
mkdir -p proto
cp <path-to-this-repo>/proto/emacs_rpc.proto proto/
#+end_src

** 3. Generate the client stubs

#+begin_src shell
uv run python -m grpc_tools.protoc -I proto \
    --python_out=. --grpc_python_out=. proto/emacs_rpc.proto
#+end_src

This produces =emacs_rpc_pb2.py= (the messages) and
=emacs_rpc_pb2_grpc.py= (the service).  Commit both.

** 4. Wrap the wire into a natural call shape

The wire is envelope-based (=session_id=, =correlation_id=, =CallOp=):
gRPC has no sessions of its own, so every client negotiates one first
with =OpenSession=, and a "natural" call cannot be expressed directly in
the proto -- the wrapper hides that plumbing so a call reads as function
name + values (like Lisp's =funcall=).

#+begin_src python
"""demo.py -- talk to the Emacs bridge over its Unix socket."""
import grpc
import emacs_rpc_pb2 as pb
import emacs_rpc_pb2_grpc as api

def to_value(v):
    value = pb.Value()
    if v is None or v is False:
        value.nil_value = True
    elif v is True:
        value.true_value = True
    elif isinstance(v, int):
        value.integer = v
    elif isinstance(v, float):
        value.real = v
    elif isinstance(v, str):
        value.text = v
    else:
        raise TypeError(f"cannot send {type(v).__name__} over the bridge")
    return value

def from_value(v):
    kind = v.WhichOneof("kind")
    if kind == "integer":
        return v.integer
    if kind == "real":
        return v.real
    if kind == "text":
        return v.text
    if kind == "true_value":
        return True
    return None                    # nil and anything unmapped

class Emacs:
    """One session; call(name, *values) reads like funcall."""

    def __init__(self, socket):
        self._stub = api.EmacsRpcStub(grpc.insecure_channel("unix:" + socket))
        self._session = self._stub.OpenSession(
            pb.OpenSessionRequest(protocol_version=1)).session_id

    def call(self, name, *values):
        req = pb.CallRequest(session_id=self._session,
                             op=pb.CallOp(function_name=name))
        req.op.arguments.extend(to_value(v) for v in values)
        resp = self._stub.Call(req)
        if resp.HasField("error"):           # a Lisp signal, not a crash
            raise RuntimeError(f"{resp.error.symbol}: {resp.error.message}")
        return from_value(resp.value)
#+end_src

** 5. Initiate and call

#+begin_src python
# In the running Emacs:
#   (emacs-rpc-bridge-start)               -- or via (require 'grpc-bridge)
#   (emacs-rpc-bridge--socket-file)        -- the value goes in SOCKET below
# (default on Linux with XDG_RUNTIME_DIR: /run/user/<uid>/emacs-rpc-bridge-<uid>.sock)

emacs = Emacs(SOCKET)
emacs.call("+", 1, 2)                # -> 3
emacs.call("concat", "hel", "lo")    # -> "hello"
#+end_src

Scalar mapping: =None/bool <-> nil/t=, =int/float/str= as-is (=bytes= as
unibyte).  Lisp objects other than scalars and symbols come back as
opaque session-scoped =handle= ids and are consumed through
=WithBuffer=/=ReleaseHandles= (see the proto); Lisp signals arrive as
structured errors (oneof =value|error=), transport problems as ordinary
gRPC statuses.

* Anatomy of =src/module.cpp=

When you add real functionality, only three things are involved:

- Write a callback with the shape
  =emacs_value (emacs_env *env, ptrdiff_t nargs, emacs_value args[],
  void *data)=.
- Convert arguments and results with the module API helpers.
- Register it in =emacs_module_init= with =defun= and =env->make_function=,
  which fixes its name and argument count.

=emacs_module_init= is the only entry point Emacs calls, and
=plugin_is_GPL_compatible= must exist for the module to be accepted.
